# UI 设计说明模板

按需裁剪本模板。页面少时可以合并章节，页面多时保留总览表并压缩单页描述。

## 1. 项目概览

| 项目 | 内容 |
| --- | --- |
| 终端形态 | 移动端 H5 / App / Web / 其他 |
| 原型范围 | 多少个页面、多少个弹层、多少个关键状态 |
| 视觉基调 | 例如浅色极简、深色科技、品牌强化 |
| 目标用户任务 | 用户在这套界面里要完成什么 |
| 本文用途 | 前端开发实现 / 联调说明 / 组件拆分依据 |

## 2. 页面与状态总览

| 页面/状态 | 作用 | 入口 | 出口 | 备注 |
| --- | --- | --- | --- | --- |
| 首页 | 浏览与分发 | App 启动后进入 | 搜索、详情、分类 | 含吸顶搜索与活动 Banner |

## 3. 全局视觉规范

### 3.1 色彩

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| 主色 | `#xxxxxx` | 主按钮、重点标签、关键高亮 |
| 辅助色 | `#xxxxxx` | 次级提示或装饰 |
| 成功/警告/错误 | `#xxxxxx` | 语义反馈 |
| 页面背景 | `#xxxxxx` | 主背景层 |
| 卡片背景 | `#xxxxxx` | 内容容器 |
| 分割线/描边 | `#xxxxxx` | 边界、分隔 |

### 3.2 字体层级

| 层级 | 建议字号/字重 | 用途 |
| --- | --- | --- |
| H1 | 例如 `24px / 600` | 页面主标题 |
| H2 | 例如 `18px / 600` | 模块标题 |
| Body | 例如 `14px / 400` | 正文 |
| Meta | 例如 `12px / 400` | 辅助说明 |
| CTA | 例如 `16px / 500` | 按钮文案 |

### 3.3 间距与容器

| 规则 | 建议值 | 说明 |
| --- | --- | --- |
| 页面左右边距 | `16px` 左右 | 主内容区对齐基线 |
| 卡片内边距 | `12-16px` | 按密度分层 |
| 区块间距 | `16-24px` | 模块垂直呼吸感 |
| 主要按钮高度 | `44-48px` | 移动端优先保证可点击面积 |
| 圆角 | `8/12/16px` 分级 | 对应输入框、卡片、弹层 |

## 4. 页面级详细说明

对每个关键页面重复以下骨架。

### 4.x 页面名称

#### 页面目标

- 说明用户在本页完成的核心任务。

#### 页面结构

| 区域 | 内容 | 布局规则 |
| --- | --- | --- |
| 顶部区 | 例如导航栏、搜索框 | 是否固定、是否透明、滚动时如何变化 |
| 主体区 | 例如 Banner、卡片列表 | 单列/双列、是否瀑布流、是否分页 |
| 底部区 | 例如操作按钮 | 是否吸底、是否跟随滚动 |

#### 组件拆分

| 组件 | 职责 | 是否复用 | 关键属性 |
| --- | --- | --- | --- |
| 搜索框 | 输入搜索词并触发跳转 | 是 | 占位文案、图标、聚焦态 |
| 商品卡片 | 展示封面、标题、价格 | 是 | 图片比例、文案截断、点击区 |

#### 视觉规则

| 项目 | 说明 |
| --- | --- |
| 布局与对齐 | 例如左对齐、卡片网格、底部固定 |
| 颜色 | 例如主按钮使用主色填充，禁用态降透明 |
| 字体 | 例如标题 16px 半粗，辅助信息 12px 常规 |
| 圆角/阴影 | 例如卡片 12px 圆角，弱阴影 |

#### 状态与交互

| 场景 | 触发 | 界面反馈 |
| --- | --- | --- |
| 默认态 | 首次进入页面 | 显示默认数据 |
| 加载态 | 页面请求中 | 骨架屏/Loading |
| 空态 | 无数据返回 | 展示空态插画与引导按钮 |
| 错误态 | 请求失败 | Toast 或页内错误提示 |
| 激活态 | 点击/选中 | 颜色、描边、图标变化 |

#### 开发备注

- 标记实现风险、依赖后端字段、待设计确认项。

## 5. 组件复用建议

| 组件族 | 复用页面 | 差异点 | 建议 |
| --- | --- | --- | --- |
| 顶部导航栏 | 首页、列表页、详情页 | 返回按钮与标题样式不同 | 抽基础容器，配置左右槽位 |

## 6. 响应式与异常场景

### 6.1 响应式

- 说明断点、最小宽度、安全区、横竖屏处理。

### 6.2 文案与资源异常

| 场景 | 处理建议 |
| --- | --- |
| 标题过长 | 两行截断，超出省略 |
| 图片加载失败 | 使用占位图或纯色底板 |
| 标签过多 | 超出折行或滚动，不压缩主信息 |
